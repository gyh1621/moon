# 书籍缓存管理

设置 → **缓存与下载**始终可用。后台任务显示当前进度；点击可取消的任务后确认取消。关闭页面不会停止下载。

书籍列表统计实际落盘文件，包括不在书架上的书籍。正文计数包含图片尚未完成的章节；进入书籍后可查看每章状态、补全缺失内容或确认清理缓存。补全复用 `source.cache_queue`，跳过完整章节，图片重试复用已有正文。

清理保留书籍元数据、目录和阅读进度；正在全本缓存的书籍必须先取消任务。本地源的原始文件不进入管理列表，不会被删除。工作目录内的符号链接只移除链接，不删除其指向的外部文件。

## 接口

- `db.book.cacheBooks()`：主进程读取所有非本地源的书籍身份、标题、路径、封面和目录，包含非书架成员。
- `book.cache.inspect(book)`：检查工作目录、独立缓存文件与专属封面；逐章区分 `cached`、`images`（正文可读）、`missing`（缺失、空文件或无法读取）。不跟随符号链接。
- `book.cache.inventoryAsync(cb)`：在主进程取得元数据后，用 `light` worker 扫盘；回调 `cb(entries)` 或 `cb(nil, err)`，返回可取消句柄。子进程不打开 SQLite。

空间统计为该书工作目录、专属封面及独立缓存书籍文件的逻辑字节数；不包含数据库或共享 HTTP/图片缓存。零字节书籍不显示。扫描仅在打开页面或点击刷新时运行，不发起网络下载；生命周期管理关闭页面后的扫描与任务订阅。
